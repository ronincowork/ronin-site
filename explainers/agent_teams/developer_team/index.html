The Developer team.

One developer session moves through a whole feature: work out what it is, plan it, build it, chase what broke, check the result. Add more developer sessions to work in parallel, and set one to run as quarterback over the rest.

job role: Developer — who the agent remains, all session long

session task: cut code — what it is doing at this moment

The role and its tasks below ship with Ronin Cowork, ready on a fresh install.

01

The role: Developer

The Developer role is the ordinary coding hat. Its briefing sets the working posture — verify before you claim, say what you did not do, bring decisions to the owner instead of guessing — and its defaults apply across every task on its shelf, so each launch starts the same reliable way.

The session keeps this role for its whole life. What changes is the task.

02

The tasks, as the work moves

A feature rarely stays one kind of work. The Developer's shelf covers the arc, and the session switches task as it goes — each switch hands the agent that task's own briefing:

riff on it · RiffOnIt Work out what a thing is and what we mean by it — a definition, not a plan.
draft plan · DraftPlan Plan a known piece of work as a doc. No code yet.
cut code · CutCode Build from an approved plan. The plan is the contract.
chase bug · ChaseBug Chase a fault to its cause and fix the cause, not the symptom.
check work · CheckWork Read-only findings on a session's output or a sweep of the code.
quarter back · QuarterBack Coordinate other sessions — dispatch, unblock, report upward.
03

Why a team, not one big session

Sessions are cheap and mortal; the work is what survives. Running the plan, the build, and the review as separate sessions keeps each agent's context small and its briefing sharp — and with several developers working in parallel, one session takes the quarter back task to read the field: it coordinates the team rather than doing the team's work for it.

The Roster shows each session's current task at a glance, so you can see the whole team's state without opening a single terminal.
