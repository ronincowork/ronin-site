Explainers / No behavioral takeover

Tools at the edges of cooperation

Ronin helps Agents cooperate. It does not tell them how to think.

Ronin is not a prompt engine, Agent harness, behavioral governor, or universal methodology. Inside the coworkspace, the Agent remains its provider's Agent, working in its normal environment.

Make ordinary actions easier

Useful tools instead of repeated terminal work.

  • Direct messagesReach another Agent without manually locating and driving its terminal.
  • Team wipeboardShare short-lived coordination without repeatedly polling every teammate.
  • Agent launchStart focused help without rebuilding the same session setup by hand.
  • Managed file coordinationGive parallel file work separate worktrees, hand-in, and a reviewed integration path when useful.

These tools support activities Agents and people already perform. They make a coordinated path available; they do not make it compulsory.

Optional working materials

An SOP is an offered path, not a behavioral lock.

Routines may offer reading, SOPs, Macros, Actions, tools, and connections to a newly launched Agent. Users choose the Routines, may customize their contents, and may launch a bare Agent with none of them. Changing a Routine does not silently rewrite an Agent already running.

Coordination is not confinement

Ronin's instructions and tools are not a sandbox or enforcement boundary. They do not restrict what an Agent process can otherwise reach through its machine, accounts, provider, or permissions.
