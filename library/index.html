Template library

A team, and everything it reads, as one download.

A template bundle holds a team template, the agent templates beside it, and the SOPs, Routines, macros and tools they name — copies, in transit only. Installing one lands every copy in your own stores on your Ronin machine, where an update never touches them. Nothing here runs; it is plain files you can read before you install.

How a bundle gets in

From the coworkspace: open the Campaign page, place Templates in a workspace, press Check the library, then pick a bundle. Ronin shows the plan first — every file, the shelf it lands on, and whether it is new, replaces a shipped copy, or would replace one of yours — and writes nothing until you press Install. A file you already own is kept unless you choose the second button.

By hand, with a file you downloaded here: 

bin/ronin-bundle plan ~/Downloads/weekly_review.json      # what it would write
bin/ronin-bundle install ~/Downloads/weekly_review.json   # the install, and its receipt

Three rules every install keeps: a copy identical to what ships is skipped; your own file is written over only when you say replace; and a tool never replaces one of Ronin's. The machine-readable index is index.json, with a sha256 per bundle that the install checks before it writes.

Have a team worth sharing?

Any team template on your machine packs the same way: bin/ronin-bundle pack <team>, or Download as a bundle on its card.
