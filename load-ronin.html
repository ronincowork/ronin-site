Surface 02 · Load Ronin

Put Ronin where your agents work.

Install on a personal laptop or desktop, a home server, or a remote virtual machine. A VM is optional. Every path leads to the same private coworkspace, reachable from devices your tailnet permits.

landing → load → terminal → setup

Before you run the command

Connect this machine to Tailscale.

Tailscale must be installed, connected, and signed in on the machine that will run Ronin. Install it on the laptop or desktop you will use to open Ronin too. If those are different devices, sign both into the same tailnet. Access is controlled by Tailscale; there is no separate non-Tailscale edition.

I have the terminal

Run one command

Paste this into a terminal on the target machine.

curl -fsSL https://raw.githubusercontent.com/ronincowork/ronin-cowork/master/scripts/get-ronin | sh

I have the machine

Hand your agent the install

Send this to an agent already running on the machine or VM where you want Ronin. It installs Ronin and returns the verified private HTTPS address.

https://github.com/ronincowork/ronin-cowork/blob/master/docs/getting-started/install.md

I need a virtual machine

Set up a Hetzner VM first

Send this to an agent on the computer in front of you. It walks you through the VM choices and purchase, prepares the new machine, and hands it to the Ronin installer.

https://github.com/ronincowork/ronin-cowork/blob/master/docs/getting-started/hetzner-vm.md

What happens next

  1. Choose a personal computer, server, or VM, and connect it and your browsing device to the same Tailscale tailnet.
  2. Copy and paste the command into your terminal, or give the instructions link to an agent on your machine.
  3. The installer verifies the release, asks once before the required machine changes, and starts Ronin.
  4. Open the one verified address printed in the terminal: https://<full-machine-name>:4810.
  5. From Ronin Home, open Machine Settings. Ronin Setup walks you through a model provider and a workspace folder.
  6. Create your first Agent and confirm it answers. Bookmark the same HTTPS address for this device or another permitted tailnet device.
  7. Good luck, and let us know how it is going.

Where can Ronin run? Your own laptop or desktop is enough; a VM is not required. A remote machine is useful when you want an always-on coworkspace from other devices permitted by the same Tailscale tailnet. No public port is required.
