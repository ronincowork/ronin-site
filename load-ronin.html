Surface 02 · Load Ronin

Put Ronin where your agents work.

Use either door below on the machine that will host Cowork. Both lead to the same private installation.

landing → load → terminal → setup

I have the terminal

Run one command

Paste this into a terminal on the target machine.

curl -fsSL https://raw.githubusercontent.com/ronincowork/ronin-cowork/master/scripts/get-ronin | sh

My agent has the terminal

Hand it the guide

Send this link to an agent already running on the target machine. Ask it to install Ronin and return the address.

https://github.com/ronincowork/ronin-cowork/blob/master/docs/install.md

What happens next

  1. Choose the machine you want to install Ronin Cowork on.
  2. Copy and paste the command into your terminal, or give the instructions link to an agent on your machine.
  3. The installer checks the machine and selects the right release.
  4. Ronin loads and starts locally.
  5. Check your terminal for the private address to open in your browser.
  6. Your browser opens the Cowork setup form.
  7. Save and submit.
  8. If you selected Ronin Services, you will confirm your email.
  9. Your browser at the same address shows your Cowork Space.
  10. Bookmark it for use on this machine or any device on your Tailscale VPN.
  11. Good luck, and let us know how it is going.

Remote machine? Keep Ronin private. Open its Cowork address from any device connected to the same VPN. No public port required.
