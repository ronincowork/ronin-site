Private remote access

Reach your Ronin machine with Tailscale.

Put the Ronin machine, your computer, and your iPhone on the same private Tailscale network. Then each device can open Cowork without putting Cowork on the public internet.

Copy this brief into an agent session running on the Ronin machine. The agent can inspect the actual host, do the machine work, and bring the sign-in step back to you. 

Help me connect this Ronin machine to Tailscale so I can reach Cowork privately from my other devices.

Work on the machine where this Ronin session is running.

1. Inspect the operating system, whether Tailscale is installed and running, and the current Ronin Cowork address. Do not change anything yet.
2. Tell me what you found and the exact plan.
3. If Tailscale is missing, use the official Tailscale distribution for this operating system. Ask before any sudo, administrator, or package-install action.
4. Start or connect Tailscale. Do not sign into an account for me. Give me the official authentication link and wait for me to complete it.
5. After I confirm the login, verify Tailscale status, identify this machine's private Tailscale address, and confirm Ronin is using it. Restart Ronin only if needed and tell me first.
6. Give me the private Cowork URL to open.
7. Do not change the firewall, public ports, SSH, DNS, exit nodes, subnet routes, or existing network configuration unless I explicitly approve it.
8. Explain how to add my computer and iPhone to the same Tailscale account, then give me a short final checklist.

Never print or store authentication keys or tokens in the session.
01

Start one Tailscale network

Go to the official Tailscale sign-up page and sign in. Use this same Tailscale account when you add each device below. Tailscale calls this private network a tailnet.

02

Add the machine running Ronin

This is the computer, home server, or cloud virtual machine that hosts your agent sessions. Paste the brief above into a Ronin session on that machine. The agent will inspect the operating system, use Tailscale's official installer if needed, and return the sign-in link for you to open. You keep control of the account login and any administrator approval.

If you prefer to do it by hand, use Tailscale's official download page.

03

Add the computer you use

  1. Download Tailscale for macOS, Windows, or Linux from tailscale.com/download.
  2. Install and open the app.
  3. Sign in with the same Tailscale account.
  4. Leave Tailscale connected while using Cowork.
04

Add your iPhone

  1. Install Tailscale from the App Store.
  2. Open it and sign in with the same Tailscale account.
  3. Allow iOS to add the VPN configuration when asked.
  4. Turn Tailscale on before opening Cowork in your browser.
05

Open Cowork

Run or restart Ronin on the host machine after Tailscale is connected. Ronin prints the private address for Cowork in that machine's terminal. Open that address from your computer or iPhone and bookmark it.

All three devices must appear in the same Tailscale network. If the address does not open, first check that Tailscale shows as connected on both the device you are holding and the Ronin host.

Ronin stays private.

Tailscale supplies the private network. Ronin does not require a public Cowork address or an additional Ronin login on that network.
