Private remote access

Reach your Ronin machine with Tailscale.

Put the Ronin machine, your computer, and your iPhone on the same private Tailscale network. Then each device can open Cowork without putting Cowork on the public internet.

01

Start one Tailscale network

Go to the official Tailscale sign-up page and sign in. Use this same Tailscale account when you add each device below. Tailscale calls this private network a tailnet.

02

Add the machine running Ronin

This is the computer, home server, or cloud virtual machine that hosts your agent sessions. For a Linux machine, open its terminal and run Tailscale's installer:

curl -fsSL https://tailscale.com/install.sh | sh

Then connect it:

sudo tailscale up

Open the sign-in link printed in the terminal and use the same Tailscale account. If the Ronin machine uses macOS or Windows, install the matching app from the official download page and sign in there instead.

03

Add the computer you use

  1. Download Tailscale for macOS, Windows, or Linux from tailscale.com/download.
  2. Install and open the app.
  3. Sign in with the same Tailscale account.
  4. Leave Tailscale connected while using Cowork.
04

Add your iPhone

  1. Install Tailscale from the App Store.
  2. Open it and sign in with the same Tailscale account.
  3. Allow iOS to add the VPN configuration when asked.
  4. Turn Tailscale on before opening Cowork in your browser.
05

Open Cowork

Run or restart Ronin on the host machine after Tailscale is connected. Ronin prints the private address for Cowork in that machine's terminal. Open that address from your computer or iPhone and bookmark it.

All three devices must appear in the same Tailscale network. If the address does not open, first check that Tailscale shows as connected on both the device you are holding and the Ronin host.

Ronin stays private.

Tailscale supplies the private network. Ronin does not require a public Cowork address or an additional Ronin login on that network.
